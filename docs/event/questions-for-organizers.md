# Questions for organizers

Codex, 2026-11-18; updated by Claude (Sonnet), 2026-11-21. Answered (team lead, 2026-11-21): at most 2 of 12 challenges per team. Ask at check-in or on the event Discord; record source and answer.

- Is generic pre-event scaffolding, tooling or AI-generated code allowed? Are disclosure, timestamps or an empty repository required?
- Can the same project be submitted to both of the two challenges? Any track restrictions?
- What platform and exact registration and submission fields, artifacts, deadlines and pitch format apply?
- Are API credits, rate limits, datasets and accounts provided? What are their usage and licensing terms?
- What hardware is provided or permitted, and how is it reserved?
- Are judging criteria weighted? Are sponsor criteria different from the final?
- Is a generic empty scaffold, private tooling or prior code allowed; must the repository start empty at kickoff?
- What are the prizes and eligibility rules?
