# Three-minute pitch template

Codex, 2026-11-18. Proposed timing; confirm actual pitch length.

| Time | Slide | Script cue |
| --- | --- | --- |
| 0:00–0:25 | Problem and user | “Meet [user]. Today [concrete problem].” |
| 0:25–0:45 | Solution | “We built [name] so [outcome].” |
| 0:45–1:55 | Live demo | “Starting here, [action]. Notice [result].” Use [demo script](demo-script.md). |
| 1:55–2:30 | How it works | “The key integration is [technology]; it enables [benefit].” |
| 2:30–3:00 | Impact and close | “For [user], this means [result]. Next: [step].” |

Prepare answers: how does it meet the prompt, what actually works, what is mocked, failure modes, privacy, feasibility, differentiation and next step? Rehearse transitions and backup video; do not claim unmeasured impact.
