# Risk register

Codex, 2026-11-18. Review at each team sync; owners are proposals until assigned.

| Risk | Mitigation | Proposed owner |
| --- | --- | --- |
| Wi-Fi fails | Test offline path and local assets; prepare a recording. | Troy |
| API quota or access fails | Check limits early; cache permitted sample responses and make a fallback. | Christian |
| Demo or deployment fails | Rehearse end to end, test clean session, keep recording and local fallback. | Christoff |
| Merge conflicts | Agree contracts and file ownership, integrate small changes often. | Helmut |
| Sleep loss | Protect shifts in [run of show](run-of-show.md), add breaks and naps. | All |
| Scope creep | Freeze features Saturday 18:00; accept only demo-critical fixes. | Helmut |
| Prior-code rule violation | Ask organizers before use, document provenance, remove anything disallowed. | Helmut |
| Missed deadline | Register and submit early; second person verifies receipt. | Christoff |
| Secrets or personal data exposed | Use environment variables, synthetic data and review artifacts before sharing. | All |
